## 🚀 Panduan Deploy ke Vercel (Sekali Klik)

### Opsi 1: Menggunakan Vercel CLI (Direkomendasikan)
1. Buka PowerShell / Terminal di direktori project:
   ```powershell
   cd "D:\AI AGENT BUNGA\01_Projects\eternal-core-project"
   ```
2. Login ke Vercel jika belum:
   ```bash
   vercel login
   ```
3. Deploy langsung:
   ```bash
   vercel --prod
   ```
   *(Pilih link default, project langsung live di domain `eternal-core-project.vercel.app` atau nama kustom)*.

### Opsi 2: Deploy melalui GitHub / Vercel Dashboard
1. Buat Git repository untuk folder `eternal-core-project`:
   ```bash
   git init
   git add .
   git commit -m "feat: launch CV. Eternal Core Project modern landing page"
   ```
2. Push ke GitHub repository.
3. Buka dashboard [vercel.com](https://vercel.com/new).
4. Import repository GitHub tersebut. Framework Preset pilih **Other** (Static Site).
5. Klik **Deploy**! Website langsung aktif secara global via Anycast CDN Vercel.
